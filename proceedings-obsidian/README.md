# Proceedings Vault

Obsidian documentation vault for the **Proceedings** codebase — a RAG immigration-intake assistant grounded on a managed **Vertex AI Search (Discovery Engine)** datastore, with a FastAPI backend, a Next.js website, and a React Native mobile app.
